\begin{result}
\subsection{Fagin's theorem}
For a finite relational vocabulary, a class of finite structures is definable
by an existential second-order sentence exactly when it is closed under
isomorphism and its encoded query language belongs to NP. The encoding gives
universe size in unary and framed relation truth tables; malformed tables are
rejected. Both directions
connect the logical semantics to the machine-backed verifier class; structures
of cardinality zero and one are included.\citep{Fagin1974,Immerman1999}

\begin{result}
\subsection{SAT completeness via order-free first-order interpretations}
All reductions in this entry are first-order interpretations of finite relational
structures of finite relational vocabularies without built-in order or numeric
predicates. CNF formulas have binary
relations $\mathrm{pos}(c,x)$ and $\mathrm{neg}(c,x)$; each element names a clause and
a variable, and a clause related to nothing is empty. SAT, the satisfiable structures,
has its encoded query language in NP. Every isomorphism-closed class whose query
language is in NP and which contains every empty structure reduces to SAT by grounding
an existential second-order definition in Tseitin style. Empty structures may differ
on their nullary relations. For classes containing every
empty structure, reducibility to SAT is equivalent to isomorphism closure and NP
membership; every class reducible to SAT has its query language in NP. Without the
empty-structure hypothesis, correctness is proved on nonempty input structures.
\citep[Chapter 7]{Immerman1999}\citep{Fagin1974}

3SAT (at most three literals per clause) and 3COL (loops allowed) are interreducible,
and 3SAT reduces to the class of simple three-colorable graph structures;
simplicity is guaranteed on yes-instances. SAT reduces to independent
set on structures with at least two elements, using Karp's occurrence graph.
Independent set, clique and vertex cover, with target size given by the cardinality
of a unary relation, are existential second-order definable.
\citep{Karp1972,GareyJohnson1979}

These are order-free variants, not completeness assertions under the standard
ordered projections. Positive-dimensional interpretations send the empty structure
to the empty, satisfiable CNF structure. The SAT-to-independent-set reduction cannot
be extended to singleton inputs with these encodings: every singleton target is a
yes-instance, whereas an empty clause on one element is unsatisfiable. SAT-to-3SAT,
hardness of 3SAT, 3COL, independent set, clique and vertex cover in this interpretation
framework, and bridges to the encoded problems remain outstanding.

\subsection{Canonical numeric structures and constant-aware interpretations}
For every $n\ge2$, an input structure on $[n]=\{0,\ldots,n-1\}$ has a
canonical expansion by $\le$, BIT and the constants $0$, $1$ and $\max=n-1$.
The constants $0$ and $1$ are distinct. On arbitrary terms $s,i$, BIT has the
exact semantics
\[
\operatorname{BIT}(s,i)\quad\Longleftrightarrow\quad
\text{bit }\operatorname{val}(i)\text{ of }\operatorname{val}(s)\text{ is }1,
\]
where bit zero is least significant. Numeric interpretations are computed
from the universe size, rather than supplied as input tables. Input functions,
constants and relations retain their interpretations, and embedding any input
formula, including quantified formulas, preserves truth under every assignment.
The construction uses the existing first-order terms and formulas.

For relational input vocabularies, forgetting the numeric expansion is a
one-dimensional interpretation whose output is isomorphic to the input;
its sentence pullback preserves truth.

More generally, let $I$ be a relational interpretation of finite dimension and
let finitely many target constants be specified by source formulas. If each
formula selects exactly one tuple inside the interpreted domain, the resulting
structure with constants admits formula and sentence pullback preserving truth
under every free-variable assignment. This existence/uniqueness condition is an
explicit hypothesis; definitions with no value or multiple values are not
assigned defaults. Source languages may already contain functions and constants;
the target language is relational with the specified additional constants.
For every canonical expansion with $n\ge2$, equality to the source terms defines
target $0$, $1$ and $\max$ with values $0$, $1$ and $n-1$.

Ordered model checking is proved below; the ordered interpretation transducer and capture
results remain open.

\begin{result}
\subsection{Exact canonical addition from order and BIT}
There is one native first-order formula $\operatorname{PLUS}(x,y,z)$ over
$\le$ and BIT, independent of the universe size, such that for every canonical
structure on $[n]=\{0,\ldots,n-1\}$ with $n\ge2$ and every assignment,
\[
\operatorname{PLUS}(x,y,z)\quad\Longleftrightarrow\quad
\operatorname{val}(x)+\operatorname{val}(y)=\operatorname{val}(z).
\]
The equality is ordinary natural-number addition. No hypothesis that the sum
fits is required: whenever $\operatorname{val}(x)+\operatorname{val}(y)\ge n$,
the formula rejects every candidate $z\in[n]$. Input vocabularies may include
functions, constants and relations; their interpretations do not affect this
numeric formula. BIT is indexed from the least significant bit.

This formalizes the PLUS part of Immerman's arithmetic-definability theorem,
using his generate/propagate carry characterization with the bit orientation
reversed.\citep[Proposition 1.9 and Theorem 1.17(1)]{Immerman1999}
The formal proof reuses the library's propagation characterization and Lean's
bit-vector carry and addition theorems. Bit Sum, TIMES and full-tuple BIT are
proved below, followed by numeric-preserving full-tuple composition.

\subsection{The native Bit Sum Lemma}
There is one native first-order formula $\operatorname{BSUM}(x,y)$ over
canonical order and BIT, independent of the universe size, such that for every
canonical structure on $[n]$ with $n\ge2$,
\[
\operatorname{BSUM}(x,y)\quad\Longleftrightarrow\quad
\operatorname{val}(y)
=\bigl|\{i\in\mathbb N : \operatorname{BIT}(\operatorname{val}(x),i)\}\bigr|.
\]
Every input has exactly one output in $[n]$: the number of set bits is at most
the input's value. The formula works for non-power-of-two universe sizes and
arbitrary interpretations of the input vocabulary.

This proves the Bit Sum Lemma used in Immerman's arithmetic-definability
theorem.\citep[Lemma 1.18 and Theorem 1.17(1)]{Immerman1999}
Immerman's historical notes credit Barrington, Immerman and
Straubing.\citep{BarringtonImmermanStraubing1990}
The formal construction packs a balanced addition tree into eight bounded
element witnesses, a variant of the source's packed running-sum proof. Its
native decoder uses fixed chains of PLUS formulas and exact binary shifts;
no multiplication relation or semantic certificate is assumed. The supporting
shift formula has exact semantics $z=x\cdot2^e$ and rejects every candidate
when the product is outside $[n]$. A fixed finite disjunction covers small
inputs. The native TIMES and full-tuple BIT formulas below reuse this result;
numeric-preserving full-tuple composition is proved below.

\subsection{Exact canonical multiplication from order and BIT}
There is one native first-order formula $\operatorname{TIMES}(x,y,z)$ over
canonical $\le$ and BIT, independent of the universe size, such that for every
canonical structure on $[n]$ with $n\ge2$ and every assignment,
\[
\operatorname{TIMES}(x,y,z)\quad\Longleftrightarrow\quad
\operatorname{val}(x)\operatorname{val}(y)=\operatorname{val}(z).
\]
The product is the ordinary natural-number product. There is no hypothesis that
it fits: if the product is at least $n$, every candidate $z\in[n]$ is rejected.
If the product is below $n$, exactly one output satisfies the formula. This works
for non-power-of-two universe sizes and arbitrary interpretations of the input
vocabulary; BIT is indexed from the least significant bit.

The construction is a carry-table variant of the source's packed short sums:
eight global words store block-boundary carries and sixteen local words verify
each block, with both endpoints matched to the global words. Exact native PLUS,
shifts and Bit Sum check the column equations. All witness bounds are proved for
every $n\ge257$, and one fixed finite disjunction covers smaller inputs.
The formula assumes no multiplication relation or semantic certificate.

\begin{result}
\subsection{Lexicographic tuple order, successor and canonical constants}
For every base $n\ge2$ and dimension $k\ge0$, the full tuple universe
$[n]^k$ is in bijection with $[n^k]$ through the rank
\[
  \operatorname{rank}(x)=\sum_{i=0}^{k-1}x_i n^{k-1-i}.
\]
The inverse recovers coordinate $i$ by division by $n^{k-1-i}$ and remainder
modulo $n$. Numerical rank order is exactly the first-coordinate-most-significant
lexicographic order: $\operatorname{rank}(x)<\operatorname{rank}(y)$ iff some
coordinate $i$ satisfies $x_i<y_i$ and every earlier coordinate agrees.
The construction reuses the existing tuple enumeration by reversing coordinates;
it works for arbitrary bases, including nonpowers of two.

Native quantifier-free formulas over the canonical source structure define both
strict and weak tuple order with these exact rank semantics. For positive dimension,
coordinate equalities define the target constants
\[
  (0,\ldots,0),\qquad (0,\ldots,0,1),\qquad (n-1,\ldots,n-1),
\]
with ranks $0$, $1$ and $n^k-1$. Their existence and uniqueness are proved in the
full tuple interpretation, so the constant-aware formula/sentence pullback applies.
At dimension zero, the rank bijection still exists and its universe is a singleton;
no two distinct constants are asserted there.

A native successor formula holds exactly when
$\operatorname{rank}(y)=\operatorname{rank}(x)+1$.
Its carry characterization increments one coordinate, keeps earlier coordinates equal,
and changes every later digit from $n-1$ to $0$. It rejects all pairs in dimension
zero and rejects every successor of the maximum tuple, including wraparound to zero.
The generic carry compiler is quantifier-free whenever its supplied source successor
formula is quantifier-free, as in Exercise 1.33(2) with source SUC available.
In the library's $\le$/BIT basis, the canonical source successor instead uses one
universal element quantifier to express adjacency; the compiled tuple formula has
one such quantifier in each carry alternative. No unconditional quantifier-free
claim is made for this basis.

$\operatorname{TBIT}_k(x,y)$ over canonical $\le$ and BIT such that, for every
source size $n\ge2$ and all $x,y\in[n]^k$,
\[
\operatorname{TBIT}_k(x,y)\quad\Longleftrightarrow\quad
\text{bit }\operatorname{rank}(y)\text{ of }\operatorname{rank}(x)\text{ is }1.

\subsection{First-order model checking in logarithmic space}
For a finite relational vocabulary and a first-order sentence $\varphi$ whose
atomic formulas are relation symbols and equality applied to variables, the
encoded query language of the finite models of $\varphi$ is in L; hence the
query language of every first-order definable class of finite structures is in
L. The encoding gives the universe size in unary, then one framed truth table
per relation symbol in the order of the vocabulary, entries indexed by the
tuple index; malformed inputs are rejected, and the empty structure and nullary
relations are included. The decider is a counter program with random access to
its input: it checks the shape of the input, then evaluates $\varphi$ with one
register per bound variable, reading table bits by index arithmetic. Counter
programs whose registers stay polynomially bounded, and more generally machines
querying input bits with logarithmic states, run in logarithmic space by a
multi-pass simulation.\citep[Theorem 3.1]{Immerman1999}

\begin{result}
\subsection{Canonical ordered model checking in logarithmic space}
Fix a finite relational input vocabulary and a first-order sentence $\varphi$
over its expansion by $\le$, BIT and the genuine constants $0$, $1$ and $\max$.
On every universe $[n]$ with $n\ge2$, these numeric symbols have their canonical
meanings, including inside quantified formulas. The encoded query language of
structures satisfying $\varphi$ belongs to L.

The input encoding gives cardinality in unary and framed truth tables for the
input relations, in the existing first-coordinate-least-significant tuple-index
order. Numeric tables are not supplied. Incorrect table shapes and sizes zero
and one are rejected. The native multi-tape decider uses $O(\log(N+1))$ work
space, where $N$ is the full encoded input length and the vocabulary and sentence
are fixed. Read-only input and write-only output are excluded from work space.
The contract is at the structure encoding; it makes no claim about raw bit
strings outside that encoding's image.

This proves the relational-input case of
\href{https://people.cs.umass.edu/~immerman/book/ch3.pdf\#page=1}{Immerman's
Theorem~3.1}, with the library's explicit framing and tuple-order conventions.
\citep{Immerman1999}
The construction reuses the existing shape checker and quantified counter-program
control, and Christian Reitwiessner's native binary arithmetic and digit-access
certificate. Binary value and index storage, as well as arithmetic intermediates,
are charged by the native simulation. No time bound for digit access is asserted.
The next entry supplies the canonical full-tuple interpretation transducer;
restricted-domain ordered reductions, projections and capture remain open.

\begin{result}
\subsection{Canonical full-tuple ordered interpretations as logspace transducers}
Fix finite relational source and target input vocabularies, a tuple dimension
$k\in\mathbb N$, and a canonical full-tuple interpretation $I$ of dimension $k$
defining each $r$-ary target input relation by a first-order formula over the
source vocabulary expanded by canonical $\le$, BIT and the constants $0$, $1$
and $\max$. The total transducer \lean{encodedMap} maps every well-formed
encoded source structure of cardinality $n\ge2$ to the encoded target structure
on the canonical rank universe $[n^k]$ numbered by the
first-coordinate-most-significant lexicographic bijection \lean{lexEquiv},
serializing only the target input relations in the existing
first-coordinate-least-significant \lean{tupleIndex} table order. The output
has cardinality $n^k$ and encoded bit length
\[
  2n^k+1+\sum_{j}(2(n^k)^{r_j}+1);
\]
target numeric predicates are not serialized as additional tables. Sources with
invalid table shapes or cardinality $0$ or $1$ map to the fixed malformed
sentinel $(0,[\,],\dots,[\,])$ with one empty table too many, outside every
target query language. One fixed multi-tape Turing machine computes
\lean{encodedMap} in logarithmic work space relative to \lean{encStructure}.

When $k>0$, a well-formed source with $n\ge2$ produces a well-formed target
with $n^k\ge2$. Equipped with its own canonical order, BIT and constants on
$[n^k]$, the decoded target is isomorphic to the interpreted full ordered
structure via \lean{encodedModelEquiv}, with every tuple retaining its exact
natural-number rank \lean{lexRank}. Consequently, for every sentence $\varphi$
over the expanded target language and every $k>0$, \lean{encodedMap} is a
logarithmic-space many-one reduction from the pulled-back ordered query
language of $I.\text{\lean{onSentence}}(\varphi)$ to the target ordered query
language of $\varphi$.

This proves the full-domain canonical transducer case of
\href{https://people.cs.umass.edu/~immerman/book/ch3.pdf\#page=4}{Immerman's
Proposition~3.5}, using the numeric lifting of Remark~1.32 and
Exercise~1.33.\citep{Immerman1999}
The counter-program transducer checks source shape and $n\ge2$, writes the
unary header of length $n^k$, and streams each target relation table by
converting each target argument's rank to its reversed base-$n$ coordinates
under the source evaluator. It shares the header, table-framing and rejection
output routines with the order-free interpretation transducer below. The bound
is for a fixed vocabulary, dimension and interpretation relative to the
structure encoding; it does not claim a canonical numeric target for $k=0$,
automatic numeric preservation on restricted domains, isomorphism-closed
class-level ordered reduction closure, or first-order projection completeness.

\begin{result}
\subsection{Order-free interpretations induce logspace reductions}
For finite relational vocabularies, every fixed finite-dimensional
first-order interpretation without built-in order induces a total
logarithmic-space transducer on encoded structures. The encoding gives
universe size in unary and framed relation truth tables. The transducer
counts domain tuples and streams the interpreted relation tables,
reconstructing elements by their ranks instead of storing the output.

Consequently, an order-free interpretation reduction from $K$ to an
isomorphism-closed class $K'$ induces a logspace many-one reduction between
their encoded query languages. Membership in L or P therefore transfers
from the target query language to the source. Parsed structure data with invalid
table sizes map to fixed invalid target data; this is the shape check within
the encoding-relative contract. Empty universes, empty interpreted domains,
nullary relations, and dimension-zero interpretations are included.
These statements concern the order-free general layer; the canonical full-tuple
ordered transducer is covered in the preceding entry.
\citep{Immerman1999,Sipser2013}

\begin{result}
\textbf{First-order projection infrastructure.}
With separate numeric and input vocabularies, each projection formula selects a
constant or one signed input-relation bit using numeric tests alone. For a fixed
numeric structure and variable assignment, the same selected literal works for
every interpretation of the input relations. The finite numeric cases are
mutually exclusive and exhaustive. Projections with finite coordinate types
compose, with the composite structure isomorphic to successive interpretation;
quantifier-free numeric definitions and guards remain quantifier-free under
composition. A concrete client is loop-free graph complement.
\citep[Definitions 3.3--3.6]{ImmermanLandau1995}

This is a vocabulary-parametric, relativized framework: output domains may be
restricted by numeric formulas, and interpreted vocabularies are relational.
It does not yet specialize to positive-dimensional full tuple universes with
canonical order and BIT, certify a logspace transducer, or prove Circuit Value
completeness under first-order projections. The classical quantifier-free convention of the cited source
excludes BIT.

\begin{result}
\textbf{Quantifier-free reductions and their automation.}
A class of finite structures is quantifier-free reducible to another when a
first-order interpretation whose domain and relation formulas are quantifier-free
maps the members of the first class into the second and the other finite
structures outside it. Quantifier-free reducibility implies first-order
reducibility and is reflexive on isomorphism-closed classes of a relational
vocabulary and transitive; for a one-dimensional interpretation whose domain
formula always holds, correctness may be stated on the input universe itself.
The tactics \texttt{fo\_qf}, \texttt{fo\_iso\_closed}, \texttt{fo\_simp} and
\texttt{fo\_reduction} prove quantifier-freeness and isomorphism closure and
reduce a reduction goal to its semantic statement. As clients, independent set,
clique and vertex cover, posed as a graph with a unary relation whose cardinality
is the target size, are pairwise quantifier-free reducible; Karp's
clique-to-node-cover reduction is the composite of complementing the edges off
the diagonal and complementing the size relation. Edge relations need not be
symmetric and loops are ignored; on simple graphs these are the usual
problems.\citep{Karp1972,GareyJohnson1979,Immerman1999}

These reductions use no order or other numeric predicates, and they are a
different notion from the quantifier-free projections of the previous entry,
which select a single input literal for each output relation. The structure
classes are not connected here to the encoded NP-complete problems.

\begin{result}
\subsection{Polynomial time is strictly smaller than exponential time}
For languages of finite bit strings,
\[
\cc{P}\subsetneq\cc{EXP}.
\]
The separating language is given by a machine diagonalization. Here EXP is the
union of deterministic time classes with bounds $2^{n^k}$. The supporting time
hierarchy uses a polynomial simulation gap; this entry does not claim the sharp
$f\log f$ hierarchy.\citep[Chapter 3]{AroraBarak09}

\begin{result}
\subsection{Ladner's theorem}
If $\cc{P}\ne\cc{NP}$, there exists a language of bit strings in NP which is
neither in P nor NP-complete under polynomial-time many-one reductions.
The witness is a padded satisfiability language with a polynomial-time padding
exponent. This is a conditional intermediate-degree theorem; it does not assume
an intermediate problem as additional input.\citep[Theorem 3.3]{AroraBarak09}
\decl{Complexity/Computability/Complexity/Classes/Ladner.lean}{445}{Cslib.Complexity.Ladner.exists_NP_not_P_not_NPComplete}
\end{result}

\begin{result}
\subsection{Karp--Lipton collapse}
If SAT has polynomial-size Boolean circuits on its encoded inputs, then
\[
\cc{PH}=\Sigma^p_2.
\]
In particular this follows if every NP problem, under its encoding, is the
preimage of a language in P/poly. The polynomial-time computation of the
self-reduction and evaluation of circuit advice are part of the development.
The circuit hypothesis is nonuniform.\citep{KarpLipton1980}

\begin{result}
\subsection{Plain Kolmogorov complexity is uncomputable}
Let $K(x)$ be the minimum bit-string description length of $x\in\mathbb N$
under the library's universal partial-computable description method. Then
$K(x)\to\infty$ as $x\to\infty$, but every total computable unbounded function
$f:\mathbb N\to\mathbb N$ satisfies $K(x)<f(x)$ for infinitely many $x$.
In particular, $K$ is not computable. This is plain complexity, often denoted
$C$ in the literature, not prefix-free complexity.\citep{LiVitanyi2019}

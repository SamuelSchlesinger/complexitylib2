\section{Sensitivity and query complexity}

For total Boolean functions on $n$ bits, write $s$ for maximum sensitivity,
$bs$ for maximum block sensitivity, $C$ for certificate complexity, and $D$
for deterministic decision-tree depth. A subscript $b$ restricts a maximum
to inputs with output $b$; it is zero if there are no such inputs.

\begin{result}
\subsection{Polynomial relations between query measures}
For every total Boolean function $f$,
\[
C(f)\le s(f)\,bs(f)\le bs(f)^2,\qquad
D(f)\le C(f)\,bs(f)\le bs(f)^3.
\]
The formal development also gives $C(f)\le2s(f)^5$ and $D(f)\le4s(f)^9$,
using the existing sensitivity theorem and degree bounds.
These are upper bounds for exact deterministic queries, with no promise
on the input.\citep{Nisan1991,BuhrmanDeWolf2002,Huang2019,NisanSzegedy1994}

\begin{result}
\subsection{Monotone measures and symmetric evasiveness}
For monotone $f$, $C(f)=bs(f)=s(f)$ and $D(f)\le s_0(f)s_1(f)\le s(f)^2$.
Separately, every nonconstant symmetric Boolean function on $n$ bits is
evasive: $D(f)=n$. Symmetry means dependence only on Hamming weight.
Thus, for $\mathrm{Th}^n_j$, which accepts iff at least $j$ bits are true,
with $1\le j\le n$,
\[
D(\mathrm{Th}^n_j)=n,\qquad
C(\mathrm{Th}^n_j)=bs(\mathrm{Th}^n_j)=s(\mathrm{Th}^n_j)
 =\max(j,n+1-j).
\]
The equality of the three local-change and certificate measures requires
monotonicity; it is not asserted for arbitrary functions.

\subsection{Approximate degree of disjunction}

\begin{result}
\subsection{Superquadratic separation of sensitivity and block sensitivity}
There is a fixed real exponent $\alpha>2$ and a family of nonconstant Boolean
functions $F_m$ on positive, varying arities such that $F_m(0)=0$ and
\[
s(F_m)^\alpha\le bs(F_m,0),\qquad bs(F_m,0)\longrightarrow\infty.
\]
Here $0$ is the all-false input, and $bs(f,0)$ is block sensitivity at that
specific input. In particular, for every real $c$ there exists a nonconstant
$f$ with $c\,s(f)^2<bs(f)$, so no universal quadratic upper bound holds.
The exponent is existential, not an assertion for every $\alpha>2$.
The linked construction ports OpenAI's formalization through the earlier
complexitylib development and connects it to the library's public measures.

\begin{result}
\subsection{Element distinctness for entries below \texorpdfstring{$n$}{n} on the word RAM}
On the bounded-word RAM with the standard basis of operations, whose registers and memory cells
hold $w$-bit words, whose every instruction costs one unit, and on which writing a constant or an
operation result of more than $w$ bits faults, a single fixed program decides whether a list of $n$ naturals, each smaller than
$n$, has no duplicates: at every word size
$w\ge 2(\lfloor\log_2\max(1,n)\rfloor+1)$ it halts within
$16(n+1)$ instructions, the final halt included, with output $1$ exactly when the entries are
distinct. Every promised input fits at this threshold, including the empty list at $w=2$.
Hence the problem is in linear time on the word RAM. The program allocates a zeroed
table of $n$ flags and uses each entry as an address into it (direct addressing), so it is not a
comparison algorithm. The bound on the entries is part of the instance type; unrestricted element
distinctness is not treated. Uniform decision requires one program for all word sizes above the
threshold, as in the transdichotomous model. The machine, its time classes and its structured
programs, which compile with identical instruction counts, are adapted from the Lean
formalization accompanying the tromino undecidability paper.

\begin{result}
\subsection{Word-RAM decision grows with the basis of operations}
The word RAM is parameterized by a basis: operation symbols with arities (a circuit signature),
the value of every operation at each word size $w$, and the operations whose value may depend on
$w$. Registers, memory, control flow and overflow faults are the same for every basis; an
operation whose value is at least $2^w$ faults. The standard basis has addition, truncated
subtraction, multiplication, division, remainder, bitwise and, or and exclusive or, both shifts,
and the word size. The arithmetic basis has the first five, the operation symbols of the
lean-trominoes RAM, here on unsigned words with truncated rather than signed subtraction, and the
additive basis the first two. A map of bases sends each operation to one of the same arity that,
at each word size, has the operation's value, and an operation not marked as reading the word size
to one not so marked.

Translating a program along such a map replaces only its operation symbols, and the translated
program takes exactly the same step from every state: the same successor, output or fault. Hence
it halts with the same output after the same number of instructions, and uniform time-bounded
decision, linear time and polynomial time over a basis imply the same statements, with the same
time bounds and word-size thresholds, over every basis it maps into; for linear and polynomial
time the same constants witness both statements. Simulating an operation by a
program over a smaller basis is not established, and no separation between the classes over
different bases is claimed.

\begin{result}
\subsection{RAMs over configurable value domains}
A RAM model specifies its value, address, configuration and literal-symbol types, operation and
test signatures, and their partial interpretations. Registers are finite and named; the program
counter indexes a finite instruction list. Memory is indexed by the chosen address type.
Loads and stores use an explicit partial conversion from a value to an address. Produced values,
moved or returned values, and control labels have configurable validity checks. A failed test
faults rather than taking its false branch. For every fixed model, configuration, program and
initial state, a halting execution with output $v$ and cost $n$ exists exactly when the
fuel-bounded interpreter returns $(v,n)$ for some fuel. Both the output and cost are unique;
the final halt costs one instruction.

Every existing word-RAM basis embeds into this core with identical steps, faults, outputs and
instruction counts, even from arbitrary initial states. Its existing unchecked moves and
unbounded program counter are preserved. A separate signed-integer instance uses the
lean-trominoes range $-2^{w-1}\le v<2^{w-1}$ for $w>0$, checked moves and halts, and natural
addresses and control labels below $2^w$.

Algebraic instances store tagged natural words or exact field elements. Only the word tag can
address memory. They support exact real arithmetic and comparison, or arithmetic and equality
over prime fields; real interpretation is noncomputable mathematical semantics. Constants are
natural-word or rational symbols, with a nonzero-denominator check in the field. These variants
use checked word arithmetic and one tagged memory, rather than the two arrays and modular word
arithmetic of the cited real-RAM model. No field-to-word conversion, bit-cost simulation or
complexity-class equivalence is claimed. Input layout is an explicit caller convention.

\begin{result}
\subsection{Additive word-RAM simulation with charged preparation}
Let $p$ be a fixed word-RAM program with $r$ named registers, using only constants, copies,
addition, truncated subtraction, indirect loads and stores, equality and unsigned comparison,
jumps and halting. Set
\[
R=r+5,\qquad \ell(m)=\lfloor\log_2\max(1,m)\rfloor+1,\qquad
A_r=8(\ell(R)+1),\quad B_r=(24+R)(\ell(R+5)+2).
\]
There is an executable compiler, independent of input and word size, into the library's
natural-number RAM with logarithmic instruction costs. If the input list $u$ has length and
entries below $2^w$, and $p$ halts on $u$ with output $v$ after $t$ source instructions,
including its final halt, the prepared target program halts with the same output within cost
\[
(A_r+B_r)(t+|u|+1)(w+1).
\]
Its external input is five zeros followed by $|u|$ and the entries of $u$. Installing this
fixed length-bearing convention is uncharged. The target then copies the header and words
backwards to address $R$, clears the prefix, initializes the compiler registers and executes
the translated program; every instruction, including the final output copy and jump, is charged.
The separate padded-input theorem starts with $R$ supplied zeros followed by $|u|$ and $u$,
and bounds the compiler execution by $A_r(t+1)(w+1)$.
Neither statement certifies an encoding reduction from an arbitrary bare list:
bare RAM inputs $[]$ and $[0]$ initialize identical states.

This is a forward simulation of successful runs, not reflection of source overflow or
falloff faults. Word-width access, multiplication, division, bitwise operations and shifts are
outside the supported fragment. The source model adapts the lean-trominoes formalization;
the target is the library's documented natural-number adaptation of Cook--Reckhow RAM.
No Turing-machine simulation or complexity-class equivalence is asserted.

potential inequalities

\begin{result}
\subsection{Recursive van Emde Boas sets: functional correctness}
For every depth $d\geq 0$, let $U_d=2^{2^d}$. A valid recursive van Emde Boas tree
represents a finite subset of $\{0,\ldots,U_d-1\}$. Inserting any $x<U_d$ preserves
the invariant and changes the represented set $S$ to $S\cup\{x\}$, including duplicate
insertions. Membership agrees with $S$. For every natural query $x$, including queries
outside the universe, successor returns $y$ exactly when $y\in S$, $x<y$, and every
$z\in S$ with $x<z$ satisfies $y\leq z$; it returns no key exactly when every element
of $S$ is at most $x$. The representation stores the minimum outside recursive clusters,
caches the maximum, and maintains a recursive summary of nonempty clusters.

A proposed contiguous layout uses a five-word header, one summary and $U_d$ cluster
records at depth $d+1$. Its record-size recurrence
$S_0=5$, $S_{d+1}=5+(U_d+1)S_d$ satisfies $S_d\leq10U_d$; the recursive address
intervals do not overlap. This is layout arithmetic, not a proved memory representation.
The operations are Lean functions: no native RAM instruction bound, charged initializer,
implemented machine-space bound or compiled adaptive controller is established here.
Deletion and predecessor are outside this result. The recursive minimum-excluded variant
follows Demaine's exposition, whose notes credit Michael Bender; it is distinguished from
the original stratified-tree implementation with $O(U\log\log U)$
storage.\citep{Demaine2015VanEmdeBoas,VanEmdeBoasKaasZijlstra1977}

\begin{result}
\subsection{Fixed-program van Emde Boas membership on the word RAM}
For every $d\geq0$ and $U=2^{2^d}$, a valid recursive van Emde Boas tree has a
five-word-header interpretation in actual memory, with recursive summary and cluster
regions. Given such represented memory, one fixed 32-register program answers membership
queries on the standard unsigned word RAM, whose basis includes multiplication, division
and remainder. Its compiled code has 213 instructions including halt, independently of
$d$, $U$, the query and the word width $w$. Each call executes at most
\[
 28(d+1)+18 = 28(\log_2\log_2 U+1)+18
\]
instructions, charging constant setup, dispatch, loop tests and jumps, and the final halt.
The abstract tree is valid, all initial registers and memory words fit $w$, and the
root address plus the full record span must also fit. Queries outside $U$ are permitted
provided they fit a word. Cached-maximum rejection precedes recursive child addressing;
surrounding memory may be arbitrary bounded words, and empty extrema may be stale.
The answer agrees with functional membership; the complete memory and persistent root
are unchanged, and the final data remains bounded. The same actual execution transfers
with its exact count to the shared generic RAM model.

Initial represented-memory construction and external argument delivery/result decoding
are not charged. This result supplies neither a charged initializer nor an implemented
space/stack bound or compiled adaptive client. The dispatcher exposes insertion and
strict-successor code, but their native correctness and resource proofs remain open.
The minimum-excluded variant follows Demaine's exposition, whose notes credit Michael
Bender; the contiguous records and register program are engineering choices, distinct
from the original stratified representation.\citep{Demaine2015VanEmdeBoas,VanEmdeBoasKaasZijlstra1977}

\begin{result}
\subsection{Timeline editing by explicit reset and replay}
For any deterministic stateful specification with an initial state, a semantic construction edits
its stored operation timeline, resets the underlying structure, and replays the edited timeline.
An edit is admissible only when its position is valid and the entire resulting ordinary history is
admissible. Realizations must supply and charge timeline editing (including storage and exposure
of the edited list), reset, and ordinary operations. With respective bounds $E(H,e)$, $R$, and
$T$ per admissible ordinary operation, the transformed operation has weight at most
\[
 E(H,e)+R+|e(H)|T.
\]
Its representation preserves the underlying current state obtained by interpreting $e(H)$ from
the initial state, and these contracts compose across subsequent timeline edits. This elementary
rebuilding construction is motivated by retroactive data structures; it supplies neither historical
query operations, efficient rollback, nor a compiled RAM controller.\citep{DIL2007}

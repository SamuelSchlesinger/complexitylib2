\begin{result}
\subsection{Toda's theorem}
\[
\cc{PH}\subseteq\cc{P}^{\#\cc{P}}.
\]
Here $\#\cc{P}$ counts witnesses of polynomial-time verifiers. The target class
uses a polynomial-time oracle program answering decision problems via bits of
one such counting function. The program is fixed before the oracle is chosen
and must work for every oracle language agreeing on valid encoded queries;
off-code answers are arbitrary. The target class has no separate query-count
parameter. The nondeterministic-machine characterization of $\#\cc{P}$
remains separate unfinished work.\citep{Toda1991}

\end{result}

\begin{result}
\subsection{Toda's theorem with a PP oracle}
\[\cc{PH}\subseteq\cc{P}^{\#\cc{P}}=\cc{P}^{\cc{PP}}.\]
$\cc{P}^{\cc{PP}}$ uses one polynomial-time oracle program, fixed before the oracle, correct
against every oracle language agreeing with some PP problem on its encoded instances; off-code
answers are arbitrary and no fixed query-count bound is imposed. It contains $\cc{P}^A$ for every $A\in\cc{PP}$.
For $f\in\#\cc{P}$, $\{(b,k)\mid k\le f(b)\}\in\cc{PP}$ via GapP, and each $\#\cc{P}$ bit request is
answered by binary search with polynomially many PP queries, substituted into the program by open
oracle substitution.

For the reverse inclusion, let $c(b)$ count the accepting strings of a PP verifier
using $p(n)$ random bits, where $n$ is the encoded input length. The function
$h(b)=2c(b)+(2^{p(n)}-1)$ is in $\#\cc{P}$, and its zero-based bit $p(n)+1$
is one exactly when $2^{p(n)}<2c(b)$. This includes zero random bits and rejects
ties. Each PP query word $w$ is replaced by the encoded pair
$(w,p(|w|)+1)$, requesting that single bit of $h$ without decoding $w$.
The resulting deterministic program is fixed before the bit oracle is chosen
and works for every oracle answering $h$ on valid pair codes, with arbitrary
answers elsewhere. Open substitution certifies uniform polynomial time,
including the cost of constructing requests and reading replies; it is not
merely a query bound. The direct shifted-count proof implements the standard
equivalence of PP and counting oracles.\citep{Toda1991,Fortnow1997}

\begin{result}
\subsection{Derandomization from average-case hardness}
Suppose a language $L$ belongs to $\cc{E}=\cc{DTIME}(2^{O(n)})$ and there is a
positive integer $c$ such that, for every sufficiently large $n$, every De Morgan
circuit of size at most $s_n=2^{\lfloor n/c\rfloor}$ agrees with $L$ on at most
$1/2+1/s_n$ of the $n$-bit inputs. Then $\cc{P}=\cc{BPP}$, uniformly for encoded
problems. The Nisan--Wigderson generator and exhaustive seed search have certified
polynomial time. The next entry obtains the hypothesis from worst-case exponential
circuit hardness.\citep{NisanWigderson1994}

\begin{result}
\subsection{Derandomization from worst-case hardness}
Suppose a language $L$ belongs to $\cc{E}=\cc{DTIME}(2^{O(n)})$ (on bit words) and
there is a real $\gamma>0$ such that, for every sufficiently large $n$, the De Morgan
circuit complexity of $L$ on $n$-bit inputs (fan-in two, every gate counted) is at
least $2^{\gamma n}$. Then $\cc{P}=\cc{BPP}$ for every encoding of every type of
instances. The hardness is converted to average-case hardness by the
Sudan--Trevisan--Vadhan encoding: at input length $N$, with $M=\lceil 40/\gamma\rceil+1$
and $b=\lfloor N/(4(M+1))\rfloor$, the slice of $L$ at length $Mb$, read as $M$ blocks
of $b$ bits, is encoded by a Reed--Muller code over the explicit field
$\mathbb{F}_{2^{4b}}=\mathbb{F}_2[X]/(g)$, with $g$ the least irreducible polynomial of
degree $4b$, concatenated with the Hadamard code; the remaining input bits are
ignored. The encoded language lies in $\cc{E}$ whenever $L$ does, with the field
arithmetic and low-degree extension certified by the time calculus, and under the
hardness hypothesis it is average-case hard for circuits of size
$2^{\lfloor N/c\rfloor}$, $c=200(\lceil 40/\gamma\rceil+2)$, at every sufficiently
large $N$; the previous result then applies. The hardness is assumed at all large
lengths, as by Impagliazzo and Wigderson; the infinitely-often variant and the

\begin{result}
\subsection{Counting algebra and the GapP characterization of PP}
For each fixed encoding, $\#\cc{P}$ is closed under pointwise addition and
multiplication, and $\cc{GapP}$ under addition, subtraction and multiplication;
the constant natural-valued and integer-valued functions belong to the
respective classes. Both classes are also closed under precomposition by a
polynomial-time function between encoded instance types. The resulting count
is exactly the original count on the mapped instance; no padding factor is
introduced. Moreover,
\[
A\in\cc{PP}\quad\Longleftrightarrow\quad
\exists g\in\cc{GapP}\ \forall x,\quad x\in A\ \Longleftrightarrow\ g(x)>0.
\]
Here $\#\cc{P}$ counts accepting certificates of a deterministic polynomial-time
verifier of polynomial certificate length; $\cc{GapP}$ consists of differences
of two such counts. These are verifier characterizations. The corresponding
nondeterministic-machine characterizations remain unfinished.

\begin{result}
\subsection{Exact terminal branches and canonical certificates}
Fix a shared-core multi-tape machine with lists of transition occurrences, an
input and an initial configuration $c$. A branch records each chosen list index
and stops at its first halted configuration. For every clock $T$, the finite
branch set consists exactly of the terminal traces of length at most $T$;
equal actions and distinct actions with the same successor retain their separate
occurrences. Padding a trace with zeros to length $T$ is a bijection onto all
length-$T$ index lists on which the explicit replay decoder succeeds.

The bijection preserves the final configuration and hence both terminal counts:
output $[\mathsf{true}]$ accepts, and every other terminal output rejects.
Out-of-range choices, a running endpoint and nonzero post-halt padding are invalid
for both classifiers. If every branch halts within $T$ and every running
configuration on those branches has a nonempty choice list, increasing the clock
preserves the branches and both counts. Finite control and a fixed finite alphabet
also give one input-independent bound on local occurrence-list lengths.

This is a combinatorial prerequisite for the classical counting-machine
characterizations.\citep{Valiant1979,FennerFortnowKurtz1994}
The certificates here contain natural-number indices. The binary implementation
and forward class-membership results are recorded next; the reverse
verifier-to-machine construction and full characterizations remain open.

\begin{result}
\subsection{Polynomial-family wide-gap robustness}
For every fixed injective encoding, polynomial-size accepting and rejecting target families
preserve the verifier-based wide-gap classes:
\[
\cc{(Poly,Poly)\text{-}WPP}=\cc{WPP},\qquad
\cc{(Poly,Poly)\text{-}LWPP}=\cc{LWPP}.
\]
Precisely, let $g\in\cc{GapP}$ and let $Y(x),R(x)$ be uniformly polynomial-time computable
lists of signed binary integers. Suppose their sets of values are disjoint at each input and
\[
x\in A\Rightarrow g(x)\in Y(x),\qquad
x\notin A\Rightarrow g(x)\in R(x).
\]
Then $A\in\cc{WPP}$. If both lists are computed only from unary input length, and are
disjoint at every natural length including zero, then $A\in\cc{LWPP}$.
The list-output bounds charge both the number of targets and their binary lengths.
Neither target index needs to be computable. Original targets may be negative, zero, or
repeated; zero is allowed on either side, provided the two families remain disjoint.
An empty list excludes the corresponding language side at that input, and empty products
have value one. Conversely, singleton accepting targets and rejection list $[0]$ recover
ordinary witnesses.

The indexed forms use uniform FP functions $y(x,i),r(x,j)$, or $y(n,i),r(n,j)$ for LWPP,
with unary indices and two independently chosen counts computed in polynomial time with unary output.
Disjointness concerns the used index ranges. These forms include the standard positive
polynomial-size families, after translating their one-based indices.
The construction follows Hemaspaandra, Hemaspaandra, Spakowski and Watanabe: the new gap
\[
h(x)=\prod_{r\in R(x)}(r-g(x))
\]
vanishes on rejection. Its accepting targets are
$\prod_{r\in R(x)}(r-y)$ for $y\in Y(x)$; disjointness makes these products nonzero.
Uniform GapP closure for this product of differences and polynomial-time binary integer
products reduce to the
one-sided target theorem.\citep[Definition 3.8, Corollary 3.11 and Theorem 3.12]{HemaspaandraEtAl2018}
The proof is Appendix~A of the full version, arXiv:1711.01250.

In particular, fixing the rejection list to $[0]$ yields
$\cc{Poly\text{-}WPP}=\cc{WPP}$ and $\cc{Poly\text{-}LWPP}=\cc{LWPP}$, with nonzero
accepting targets and an unknown accepting index.\citep[Theorems 3.1 and 3.7]{HemaspaandraEtAl2018}
The underlying counting algebra credits Fenner--Fortnow--Kurtz.\citep{FennerFortnowKurtz1994}
Oracle lowness and counting-machine characterizations remain separate.

\subsection{Uniform bounded wide-gap closure}

\[

\{x:\forall i<r(x),\ (x,i)\in A\}&\in\mathcal C,\\
\{x:\exists i<r(x),\ (x,i)\in A\}&\in\mathcal C.

\begin{result}
\subsection{Wide gaps, amplification and Boolean closure}
For every fixed injective encoding,
\[
\cc{LWPP}\subseteq\cc{WPP}\subseteq\cc{AWPP}.
\]
The WPP target may be signed, input-dependent and exponentially large: it is a
nonzero, binary-output polynomial-time integer function, with the GapP witness
equal to that target on members and zero on nonmembers.
The classical containment is credited to Fenner--Fortnow--Kurtz--Li;
this formalization squares the target and uses binary length to obtain a dyadic
normalization.\citep[Section 6.1]{FennerEtAl2003}

Every AWPP language has a GapP witness $g$ and $p\in\mathbb{N}[X]$ such that,
writing $D(x)=2^{p(|x|)}$, one has $0\leq g(x)\leq D(x)$ and
\[
x\in A\Rightarrow 7D(x)\leq8g(x),\qquad
x\notin A\Rightarrow 8g(x)\leq D(x).
\]
Three fixed rounds of the majority-of-three polynomial give this error bound;
the denominator exponent is multiplied by $27$. This is a fixed-size instance
of Fenner's amplification method.\citep{Fenner2003}
AWPP is closed under intersection, union, difference and symmetric difference
of two languages over the same encoding, as well as complement.

For SBP, every exponent $r(x)$ polynomially bounded in encoded input length admits
one \#P witness $f$ and a positive binary-output polynomial-time natural threshold $k$ with
\[
x\in A\Rightarrow k(x)\leq f(x),\qquad
x\notin A\Rightarrow 2^{r(x)} f(x)<k(x).
\]
A fixed length polynomial $q$ dominating $r$ gives $q(|x|)+1$ repetitions, raising
both the original count and threshold to that power. The request need not be computable.

\begin{result}
\subsection{Uniform AWPP error reduction}
Fix an injective bit-string encoding; $|x|$ denotes its encoded length. For every
$A\in\cc{AWPP}$ and every $r:X\to\mathbb{N}$ polynomially bounded in encoded
input length, there exist $G\in\cc{GapP}$ and $P\in\mathbb{N}[X]$ such that,
writing $D(x)=2^{P(|x|)}$, for every input $x$,
\[
0\leq G(x)\leq D(x),\qquad
\begin{aligned}
x\in A&\Rightarrow 2^{r(x)}(D(x)-G(x))\leq D(x),\\
x\notin A&\Rightarrow 2^{r(x)}G(x)\leq D(x).
\end{aligned}
\]
The requested rate $r$ need not be computable: the proof chooses a fixed
$q\in\mathbb{N}[X]$ dominating it. Given an original denominator exponent $p$,
strict majority of $12q(|x|)$ trials yields the explicit exponent $P=12qp$.
Zero exponents and a denominator of one are allowed. Uniform GapP word sums and
unary powers construct the numerator; a finite counting identity transfers the
majority tail bound without assuming an efficient sampler for the original GapP
value. The constant-error characterization and error reduction are credited to
Fenner; the factor $12$ comes from the formalized majority estimate used for BPP. Here GapP retains the verifier-based model;
counting-machine characterizations and PP-lowness are not established.
\citep{Fenner2003}\citep[Section 7.4.1]{AroraBarak09}

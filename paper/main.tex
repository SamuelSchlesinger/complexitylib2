This is a curated index of thirteen results in the Lean library, not an exhaustive
API reference. Each entry gives the statement, its model or assumptions, and a link
to the formal declaration. Links are pinned to revision \texttt{d2c5e581}.
The wording and selection remain open to Samuel's editorial direction.

Unless specified otherwise, class statements hold for any type of instances with
an injective encoding into finite bit strings; input size is encoded length.
Resource bounds and reductions refer to the library's machine definitions.
Source citations credit the mathematics; linked modules also record formalization authors.
This index was prepared and reviewed with AI assistance; prose is not machine checked.

This tour collects 70 entries spanning the library's significant results, from
machine complexity and descriptive logic to cryptography, circuit lower bounds,
proof complexity, communication, coding and circuit synthesis. Some entries group
closely related theorems. It is a statement index, not an exhaustive API reference
or a translation of proof bodies. Each entry identifies its hypotheses, model,
quantitative guarantee and scope, with links pinned to reviewed library revisions
\texttt{8d38f775}, \texttt{811ad02a} (first-order projections), and
\texttt{4f6bdaf3} (basic class developments), and \texttt{2f492c03}
(small counting classes). Selection and wording remain open to Samuel's editorial direction.

Unless specified otherwise, encoded decision problems use an injective encoding
into finite bit strings, and input size is encoded length. Class statements and
reductions refer to the library's machine definitions. Circuit-family results are
nonuniform unless uniformity is explicitly asserted. A circuit-size bound does
not by itself certify a constructor's runtime; a decoder's correctness does not
by itself certify its running time. Assumptions such as one-way functions or
circuit hardness are premises of implications, not established existence results.

Source citations credit the mathematics; linked modules record formalization
authors and port provenance. This index was prepared and independently reviewed
with AI assistance. Lean checks the formal declarations; the prose-to-Lean
comparison is a separate review, not a machine-checked equivalence proof.
